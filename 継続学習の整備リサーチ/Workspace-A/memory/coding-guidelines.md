# コーディング方針

このサンプルの初期方針。実プロジェクトで使うときに利用者が見直す。

## G-001: 変更範囲を依頼に合わせる
- 状態: サンプル既定（利用者の実プロジェクトでの合意は未取得）
- 方針: 既存の構造・命名に合わせ、無関係な大規模変更を避ける。
- 範囲: Workspace-A 内のコード変更。
- 根拠: 本サンプルの初期設定。

## G-002: 検証状況を明確にする
- 状態: サンプル既定
- 方針: 変更に応じた検証を選び、実施・未実施・失敗を区別して報告する。
- 範囲: Workspace-A の変更報告。
- 根拠: 本サンプルの初期設定。テストコマンドや実行環境の指定はない。

## 追加時の記録形式
ID / 状態（確定・提案中・廃止）/ 方針 / 適用範囲 / 根拠 / 更新日。
サンプル既定とユーザーが確定した方針を混同しない。
